Tic-Tac-Toe Game

A browser-based Tic-Tac-Toe game developed using HTML, CSS, and JavaScript. This project demonstrates core frontend development concepts, including DOM manipulation, event handling, game-state management, and responsive user interface design.
Features:
a)Two-player turn-based gameplay
b)Automatic winner detection
c)Draw game detection
d)Game reset and restart functionality
e)Responsive and user-friendly interface
